Release-blocking bug reproduced:

- Baseline JavaScript contained three valid top-level statements: `--a;`, `--b;`, and `--c;`.
- The edit changed them to `++a;`, `++b;`, and `++c;`.
- Git correctly reported `+3/-3`.
- `grasp debug:capture` reported `FILTERED — reason: formatting_only`.
- The real hook path stored `captured_diffs.filtered = 1`, stored `filter_reason = formatting_only`, invoked the mock zero times, and created zero event rows.

Cause: hunk parsing treats any diff line beginning with `+++` or `---` as if it were a file header. Inside a parsed hunk, those strings can instead be ordinary added/removed source lines whose code starts with `++` or `--`. The filtering code drops both sides, sees two empty sequences, and calls the change formatting-only.
